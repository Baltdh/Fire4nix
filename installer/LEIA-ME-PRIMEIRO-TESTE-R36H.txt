FIRE4NIX R36H — PRIMEIRO TESTE FÍSICO
=========================================

PACOTE EXPERIMENTAL PARA ROCKNIX / R36H
Este pacote combina o runtime WPE 2.54.1 compilado com SDK ROCKNIX e o
launcher nativo Fire4Nix 1.05 ARM64. O WPE 2.54.2 foi usado separadamente
na validação headless de integração contínua; ele NÃO foi copiado para cá.

O que este pacote verifica:
1. Diagnóstico EGL/GLES2 independente, com contexto pbuffer 1x1.
2. ELF ARM64 e selftest do launcher.
3. Carregamento da biblioteca WPE privada.
4. Presença das APIs WPEPlatform exigidas pelo launcher.
5. Carregamento real da página HTML offline.
6. DOM, JavaScript, CSS computado e evento de clique.
7. Abertura interativa para confirmação manual da imagem na tela 640x480.

O teste EGL é somente um diagnóstico da pilha gráfica do sistema. Mesmo quando
passa, NÃO comprova superfície Wayland, primeiro frame ou renderização do WPE.

INSTALAÇÃO NÃO DESTRUTIVA
1. Extraia o conteúdo completo deste ZIP em uma pasta nova dentro de:
   roms/ports/Fire4Nix-R36H-Primeiro-Teste-20261030
2. Não misture com a pasta de uma instalação anterior.
3. Não copie bibliotecas para /usr e não substitua arquivos do ROCKNIX.

PRIMEIRO: DIAGNÓSTICO GRÁFICO INDEPENDENTE
Abra o terminal do ROCKNIX dentro da sessão gráfica e execute:
   cd /storage/games-internal/roms/ports/Fire4Nix-R36H-Primeiro-Teste-20261030
   sh Fire4Nix-Primeiro-Teste-R36.sh --graphics-probe

O probe cria somente um contexto EGL/GLES2 offscreen de 1x1, com timeout de
15 segundos. Registra fornecedor/versão EGL, renderer GLES2 e presença do
socket Wayland. Não abre WPE nem altera configurações do sistema.
Resultado positivo esperado:
   EGL_PROBE=PASS_OFFSCREEN_CONTEXT_ONLY

DEPOIS: TESTE DO MOTOR WPE
Execute o pré-teste funcional:
   sh Fire4Nix-Primeiro-Teste-R36.sh --preflight

O teste exige:
- arquitetura aarch64;
- libWPEWebKit-2.0.so.1 e subprocessos presentes;
- API WPEPlatform disponível;
- sessão Wayland ativa para o teste HTML;
- página offline validada por JavaScript/DOM/CSS.

DEPOIS: PRIMEIRO TESTE VISUAL
Se o pré-teste terminar com ENGINE_FUNCTIONAL_TEST=PASS:
   sh Fire4Nix-Primeiro-Teste-R36.sh --open

A página Fire4Nix deverá abrir e permanecer na tela:
- três blocos coloridos;
- status "JS OK";
- botão "Testar botão" atualizando o contador de cliques.

Saia pelo atalho Ctrl+Q. Não conclua que houve sucesso visual apenas pelo
código de saída: confirme os blocos coloridos e o texto na tela.

LIMITES CONHECIDOS
- O pacote e a estrutura SD foram verificados; o R36H físico ainda não foi
  executado nesta revisão.
- O probe EGL/GLES2 offscreen não valida uma superfície Wayland do cliente.
  EGL/Mali/Wayland integrado ao WPE, primeiro frame e estabilidade prolongada
  continuam pendentes até o teste no console.
- O relatório do runtime informa fechamento estático de dependências com
  SDK ROCKNIX; isso não equivale a prova de ABI de cada biblioteca do rootfs.
- O teste headless ARM64 não prova o framebuffer nem o driver Mali do R36H.
- O pacote não instala/atualiza firmware, kernel, DTB, drivers ou /usr.
