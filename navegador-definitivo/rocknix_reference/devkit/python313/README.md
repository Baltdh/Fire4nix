# Python 3.13 build-reference snapshot

This directory stores Python build-time reference files captured from the uploaded ROCKNIX environment.

## Captured files

- `config.c` — generated CPython module configuration output; useful for understanding which builtin/optional modules were present in the build snapshot.
- `Setup` — the main optional-module setup file used by CPython's `makesetup` process.
- `Setup.bootstrap` — the builtin module bootstrap list used to bring up a functioning interpreter.
- `Setup.local` — local override hook for build-time module selection.
- `Setup.stdlib` — the standard-library module selection snapshot generated by CPython.
- `install-sh` — generic install helper script captured from the environment and useful for build-script compatibility checks.

## Notes

- These files are reference-only and are not wired into Fire4Nix at runtime.
- They are useful for Marco 2 / Marco 3 when validating Python-based build tooling and helper scripts.
